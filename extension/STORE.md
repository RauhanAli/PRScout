# Store listing

## Name

PRScout for GitHub

## Short description (≤ 132 characters)

See on any GitHub repo whether newcomers get their pull requests merged, before you spend a weekend on your first contribution.

## Long description

Picking your first open-source project is a gamble. Some repos welcome newcomers; others leave outside pull requests unanswered for months.

PRScout reads a repository's recent pull request history and answers one question: is it worth your time as a newcomer? This extension puts that answer right on GitHub, next to the repo name:

• PRScout: Worth your time
• PRScout: Not worth your time
• PRScout: Not enough evidence

Next to the verdict you get one fact, like "15 of 100 newcomer PRs merged". Click the chip to open the full PRScout report: who gets replies, how fast, and which parts of the project accept outside work, with links to the pull requests behind every claim.

On a repo's issue list, PRScout also marks issues that look like good first picks. Hover over the mark to see why.

If PRScout hasn't looked at a repo yet, the chip says "Check with PRScout". Click it and PRScout starts the analysis.

Built for Hacktoberfest and anyone making their first open-source contribution.

What it does not do:
• It never posts to GitHub or contacts anyone. It only reads.
• No login, no account, no tracking.
• It can only see github.com and the PRScout site. It has no access to your tabs or history.

The verdict comes from fixed rules, not from an AI guess. PRScout is open source.

## Category

## Privacy / data use (for the store forms)

- Data sent: the owner and repository name of GitHub repository pages you open, sent to the PRScout host to look up its report. Nothing else, no identifiers, no cookies.
- Not sold or shared, not used for anything but showing the verdict.
- Permissions: host access to github.com (to show the chip) and the PRScout host (to fetch reports).
- Firefox `data_collection_permissions`: `browsingActivity` (the repo names above).

## Single purpose (Chrome)

Show PRScout's newcomer-friendliness verdict for a GitHub repository on that repository's page.
